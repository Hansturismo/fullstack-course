Accordion Component

Accordion Closed

An accordion is a user interface component used to organize and display content in a compact way. It allows users to expand and collapse sections to reveal or hide additional information. This pattern is commonly used in FAQs, product details, settings menus, and documentation pages where space is limited but multiple pieces of information need to be available. By default, only the section headers are visible. When a user clicks on a header, the content expands smoothly, and other sections may remain closed to keep the interface clean and easy to navigate.
